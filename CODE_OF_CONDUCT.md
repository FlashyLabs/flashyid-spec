# Code of conduct

Be direct, be specific, and argue from the text. A disagreement about this
spec is settled by a vector: write the document you think should pass or fail,
and let the checker say what it does today.

Harassment, personal attacks and bad-faith participation are not tolerated,
in issues, pull requests or anywhere this project is discussed. Report a
problem to the maintainers at security@flashylabs (address to be confirmed
before launch; see SECURITY.md), or to the maintainer of
FlashyLabs/flashyid. Reports are handled privately and a reporter is never
identified without consent.
